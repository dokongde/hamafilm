```

├── charter.md   # 왜·목표·범위·제약 (항상)
├── wbs.md       # 작업 분해 + 일정 + 예산 (실행 규모면)
└── risks.md     # 리스크 대장 + 이슈 + 교훈 (돈·계약 걸리면)
```
