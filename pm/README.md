# 🗂 PM 팀 — 프로젝트 관리 지식 베이스

내가 "뭐 하고 싶다"고 말하면, Claude가 여기 있는 PM 지식(PMBOK·애자일·PMP 시험 범위)을 근거로
프로젝트를 설계해주는 시스템이다.

## 사용법

- `/pm 셀프사진관 2호점 내고 싶어` — 아이디어를 프로젝트로 설계 (차터 → 범위 → WBS → 일정 → 리스크 → 첫 액션)
- `/pm 공부` 또는 `/pm PMP 알려줘` — PM 이론/PMP 시험 내용을 지식 베이스 기반으로 설명
- `/pm 진행상황` — `pm/projects/`에 있는 프로젝트들의 상태 점검

## 디렉토리 구조

```
pm/
├── knowledge/          # PM 이론 공부 노트 (한국어)
│   ├── 01-basics.md        # 프로젝트란, 3중 제약, 생애주기
│   ├── 02-pmbok7.md        # PMBOK 7판: 12원칙, 8성과영역
│   ├── 03-process-groups.md# 5프로세스 그룹 × 10지식영역 (PMBOK 6, 시험 필수)
│   ├── 04-agile.md         # 애자일·스크럼·칸반·하이브리드
│   └── 05-tools.md         # WBS, CPM, EVM, 리스크 매트릭스 등 도구·기법
├── certifications/
│   └── pmp-guide.md        # PMP/CAPM 자격증: 요건, 시험 구조, 준비 전략
├── templates/          # 설계할 때 쓰는 템플릿
│   ├── project-charter.md
│   ├── wbs.md
│   └── risk-register.md
└── projects/           # 실제 설계된 프로젝트들이 저장되는 곳 (프로젝트당 폴더 1개)
```

## 원칙

- 설계는 항상 지식 베이스의 방법론을 근거로 하되, 하마필름 규모(1인~소규모 사업)에 맞게 테일러링한다.
  49개 프로세스를 다 돌리는 게 아니라, 작은 프로젝트엔 작은 프로세스.
- 모든 설계 결과는 `pm/projects/<프로젝트명>/`에 저장해서 나중에 이어서 관리할 수 있게 한다.
