# 🦛 하마필름 알바 계약서 세트 (독일법 기준)

독·한 병기로 작성된 워드(.docx) 양식 3종입니다. 빈칸을 채우고 인쇄해서 서명하면 됩니다.

| 파일 | 용도 |
|---|---|
| `Arbeitsvertrag_Minijob_하마필름.docx` | 근로계약서 (미니잡/단시간 근로자용, 독·한 병기) |
| `Lohnquittung_급여현금수령확인서.docx` | 급여 **현금** 지급 시 매회 받는 수령확인서 + 연간 지급대장 |
| `Stundenzettel_근무시간기록표.docx` | 월별 근무시간 기록표 (최저임금법 § 17 MiLoG 기록 의무 대응) |

## 현금으로 급여를 줄 때 꼭 알아야 할 것

1. **현금 지급 자체는 합법**입니다. 다만 "신고된 고용"이어야 합니다.
   - 미니잡센터(Minijob-Zentrale)에 직원 등록 → 정액 사회보험료·세금 납부
   - 미등록 상태로 현금만 주면 불법고용(Schwarzarbeit)으로 사업주가 벌금·추징 대상이 됩니다.
2. **매회 수령확인서(Quittung) 서명**을 받으세요. "돈을 못 받았다"는 분쟁과 세무조사 양쪽에서 사업주를 지켜주는 유일한 증거입니다. 연간 지급대장에도 매월 서명을 받아두면 더 좋습니다.
3. **매월 급여명세서(Lohnabrechnung)** 를 발급해야 합니다 (Steuerberater 또는 급여 프로그램 이용).
4. **근무시간 기록 의무**: 미니잡 직원은 일별 시작·종료·시간을 7일 이내 기록, 2년 보관 (§ 17 MiLoG). 하마필름 앱 스케줄 기록 + 이 기록표를 병행하면 안전합니다.

## 2026년 기준 숫자

- 법정 최저임금: **시급 13,90 €**
- 미니잡 한도: **월 603 €** (여러 미니잡 합산 기준)
- 계약서에 **주당 근로시간을 반드시 기재** — 비워두면 법상 주 20시간으로 간주되어 한도 초과 위험 (§ 12 TzBfG)

## 작성 순서

1. 계약서 빈칸 작성 (시급·주당 시간·지급 방법 "현금(수령확인서)" 체크) → 2부 서명, 각자 1부 보관
2. 직원을 미니잡센터에 등록
3. 매월: 근무시간 기록표 마감 → 급여 계산 → 현금 지급 + 수령확인서 서명 → 지급대장 기록

> ⚠️ 본 양식은 참고용이며 법률·세무 자문을 대체하지 않습니다. 첫 세팅은 Steuerberater(세무사)와 한 번 확인하는 것을 권장합니다.

문서 수정이 필요하면 `generate-contracts.js`(docx 생성 스크립트)를 고쳐서 다시 생성하면 됩니다: `node generate-contracts.js .`
