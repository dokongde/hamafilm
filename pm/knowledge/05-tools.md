# 05. 핵심 도구·기법

## WBS (Work Breakdown Structure, 작업분류체계)

프로젝트 전체 범위를 **인도물 중심**으로 계층 분해한 것. "이 안에 없으면 프로젝트 범위가 아니다."

- 최하위 단위 = **워크 패키지**: 기간·비용·담당을 붙일 수 있는 크기 (경험칙: 8~80시간).
- **100% 규칙**: 하위 항목을 다 합치면 상위 항목의 100%가 돼야 한다 — 빠진 것도 중복도 없이.

```
1. 2호점 오픈
   1.1 입지·계약
       1.1.1 후보지 조사   1.1.2 임대 계약
   1.2 공사·설비
       1.2.1 인테리어      1.2.2 장비 설치
   1.3 운영 준비
       1.3.1 결제·정산 세팅 1.3.2 알바 채용
   1.4 오픈 마케팅
```

## 일정: CPM (Critical Path Method, 주경로법)

- 활동 간 의존관계로 네트워크를 그리고, **가장 오래 걸리는 경로 = 주경로(critical path)** 를 찾는다.
- 주경로의 길이 = 프로젝트 최단 완료 기간. 주경로 위 활동이 하루 늦으면 전체가 하루 늦는다.
- **여유시간(Float/Slack)**: 전체 일정에 영향 없이 그 활동이 늦어질 수 있는 기간. 주경로 활동은 float = 0.
- 일정 단축 기법: **크래싱**(자원 추가 투입, 돈 듦) vs **패스트트래킹**(순차 작업을 병행, 리스크 커짐).

## 산정 (Estimation)

- **유사 산정**: 과거 비슷한 프로젝트 기준. 빠르지만 부정확.
- **모수 산정**: 단가 × 수량 (예: ㎡당 공사비). 데이터 있으면 정확.
- **3점 산정 (PERT)**: (낙관 + 4×최빈 + 비관) ÷ 6. 불확실할 때.
- **상향식**: 워크 패키지별로 산정해 합산. 제일 정확하고 제일 오래 걸림.

## EVM (Earned Value Management, 획득가치관리)

일정과 비용을 **한 화폐 단위로** 같이 보는 기법. 시험 계산문제 단골.

| 약어 | 뜻 |
|---|---|
| PV | 계획가치 — 지금까지 하기로 계획한 작업의 예산 |
| EV | 획득가치 — 지금까지 실제 완료한 작업의 예산 가치 |
| AC | 실제원가 — 지금까지 실제로 쓴 돈 |
| BAC | 총 예산 |

- **SV = EV − PV** (일정차이, 음수면 지연) / **SPI = EV ÷ PV** (1 미만이면 지연)
- **CV = EV − AC** (원가차이, 음수면 초과) / **CPI = EV ÷ AC** (1 미만이면 예산 초과)
- **EAC = BAC ÷ CPI** — 이 추세면 최종적으로 얼마 들지 예측.
- 예: 예산 10,000€ 공사, 절반 시점에 PV 5,000, 완료된 건 40%(EV 4,000), 쓴 돈 4,800(AC).
  → SPI 0.8 (20% 지연), CPI 0.83 (17% 초과), EAC ≈ 12,000€. "지연 + 예산 초과" 즉시 판독.

## 리스크 매트릭스 (확률 × 영향)

| | 영향 소 | 영향 중 | 영향 대 |
|---|---|---|---|
| **확률 高** | 주의 | 대응 필수 | 대응 필수 |
| **확률 中** | 감시 | 주의 | 대응 필수 |
| **확률 低** | 수용 | 감시 | 주의 |

리스크 대장에 기록: 리스크 / 확률 / 영향 / 대응 전략(회피·전가·완화·수용) / 담당 / 트리거 신호.

## 기타 자주 쓰는 것

- **간트차트**: 활동을 시간축 막대로. 작은 프로젝트 일정 관리는 이거면 충분.
- **RACI 매트릭스**: 작업별 R(실행) A(책임, 1명만) C(협의) I(통보) 지정. 역할 혼선 방지.
- **마일스톤**: 기간 0의 주요 시점 (계약 완료, 오픈일). 보고는 마일스톤 중심으로.
- **변경 로그 / 이슈 로그 / 교훈 대장**: 적지 않으면 반복한다.
- **킥오프 미팅**: 기획 끝나고 실행 시작할 때 전원 모여 목표·역할·규칙 공유.
