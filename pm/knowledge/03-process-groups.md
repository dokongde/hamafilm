# 03. 5 프로세스 그룹 × 10 지식영역 (PMBOK 6판 체계)

PMBOK 6판의 49개 프로세스 체계. 7판이 나왔지만 PMP 시험과 실무 표준 프레임은 여전히 이 매트릭스를 기반으로 한다.
전부 외울 필요는 없고, **어떤 지식영역이 어느 단계에서 무슨 산출물을 내는지** 흐름을 잡는 게 핵심.

## 5 프로세스 그룹

| 그룹 | 질문 | 대표 산출물 |
|---|---|---|
| 착수 (Initiating) | 왜 하는가? 누가 관련되나? | 프로젝트 차터, 이해관계자 목록 |
| 기획 (Planning) | 무엇을·언제·얼마로? | 범위기술서, WBS, 일정, 예산, 리스크 대장 |
| 실행 (Executing) | 일을 한다 | 인도물, 팀, 소통 |
| 감시·통제 (Monitoring & Controlling) | 계획대로 가고 있나? | 성과 보고, 변경 요청 |
| 종료 (Closing) | 끝났나? 배운 건? | 최종 인수, 교훈 기록 |

## 10 지식영역 — 각 영역의 핵심 한 줄

1. **통합 (Integration)** — 전체를 하나로 꿰는 것. 차터 작성, 변경 통제, 종료가 여기 속한다. PM의 본업.
2. **범위 (Scope)** — 무엇을 하고 **무엇을 안 하는지**. 산출물: 범위기술서, WBS.
   - 핵심 개념: **스코프 크립(scope creep)** — 승인 없이 범위가 슬금슬금 늘어나는 것. 프로젝트 실패 1순위 원인.
3. **일정 (Schedule)** — 활동 정의 → 순서 → 기간 산정 → 일정 개발. 도구: 간트차트, CPM(주경로법).
4. **원가 (Cost)** — 산정 → 예산 확정 → 통제. 도구: EVM(획득가치관리). 예비비(contingency) 포함.
5. **품질 (Quality)** — 요구 기준 정의(계획) → 프로세스 개선(보증) → 산출물 검사(통제).
6. **자원 (Resource)** — 사람과 물자. 산정 → 확보 → 팀 개발 → 관리.
7. **의사소통 (Communications)** — PM 업무의 약 90%. 누구에게·무엇을·언제·어떻게 알릴지 계획.
8. **리스크 (Risk)** — 식별 → 정성/정량 분석 → 대응 계획 → 감시.
   - 위협 대응 4가지: **회피 / 전가(보험·외주) / 완화 / 수용**
   - 기회 대응 4가지: **활용 / 공유 / 증대 / 수용**
9. **조달 (Procurement)** — 외부에서 사올 것 결정, 계약 유형(고정가/원가정산/시간자재), 업체 관리.
10. **이해관계자 (Stakeholder)** — 식별 → 참여 계획 → 참여 관리·감시. 격자: 권력×관심 매트릭스.

## 흐름으로 외우기 (작은 프로젝트 기준 최소 세트)

```
착수:   차터 1장 (왜/목표/제약/스폰서)  +  이해관계자 목록
기획:   범위기술서 → WBS → 일정(간트) → 예산 → 리스크 대장 (5개면 충분)
실행:   주간 체크인, 이슈 로그
통제:   계획 대비 실제 (일정·돈), 변경은 반드시 기록하고 결정
종료:   인수 확인, 정산, 교훈 3줄
```

## 시험에 자주 나오는 포인트

- 차터는 **스폰서가 승인**하고, PM에게 권한을 부여하는 문서다.
- WBS는 **인도물(deliverable) 중심** 분해다. 할 일 목록이 아니다.
- 변경 요청은 누가 내든 **통합 변경 통제**를 거쳐 승인/기각된다. PM 마음대로 반영 금지.
- 리스크 대응에서 "보험 가입"은 **전가**, "그 방식 자체를 포기"는 **회피**.
- 교훈(Lessons Learned)은 종료 때만이 아니라 **프로젝트 내내** 기록한다.
