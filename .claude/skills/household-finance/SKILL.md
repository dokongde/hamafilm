# 우리집 가계팀

가계 데이터는 `household/` 디렉토리에 있다. 요청을 아래 유형으로 분류해 담당 에이전트에게 위임한다 (Agent 도구, `subagent_type` 지정).

## 요청 유형별 처리

### 1. 결산 (예: "결산", "이번 달 정리해줘")
세 에이전트를 **병렬로** 실행한다:
- `finance-income` — 이번 달 수입 집계
- `finance-fixed-costs` — 고정비 합계와 절감 포인트
- `finance-spending` — 이번 달 지출 분석 (예산 대비, 전월 대비)

세 결과를 받은 뒤 `finance-coach`에게 넘겨 조언 섹션(잘한 것/아쉬운 것/다음 달 액션 3가지)을 받는다.
전체를 종합해 `household/reports/YYYY-MM.md`로 저장하고, 핵심 요약(수입/지출/수지/조언)을 사용자에게 보고한다.

### 2. 지출 기록 (예: "지출기록 마트 45유로", "오늘 외식 30유로 썼어")
`finance-spending`에게 위임. 항목·금액·날짜를 그대로 전달한다.

### 3. 고정비 점검·변경 (예: "고정비점검", "넷플릭스 해지했어", "월세 올랐어")
`finance-fixed-costs`에게 위임.

### 4. 수입 기록·변경 (예: "월급 올랐어", "보너스 받았어")
`finance-income`에게 위임.

### 5. 상담 (예: "이거 사도 돼?", "얼마나 저축해야 해?", "어디서 아껴야 해?")
`finance-coach`에게 위임. 질문을 그대로 전달한다.

## 규칙
- 데이터 파일에 `[채워주세요]`가 남아 있으면, 작업 결과와 함께 어떤 정보가 부족한지 사용자에게 알린다. 사용자가 정보를 주면 해당 담당 에이전트를 통해 파일에 저장한다.
- 사용자가 과거 대화 내용이나 재정 정보를 붙여넣으면, 항목별로 분류해 각 담당 에이전트에게 저장을 위임하고 `profile.md`의 "이전 대화에서 정리된 내용" 섹션에도 요약을 남긴다.
- 파일 변경 후 커밋은 사용자가 원할 때만.
